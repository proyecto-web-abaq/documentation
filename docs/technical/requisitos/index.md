# Requisitos

Especificación formal de lo que el sistema debe hacer.

- **[Requisitos (SRS)](../srs.md)**: Especificaciones de requerimientos funcionales y no funcionales (ISO/IEC/IEEE 29148:2018).
- **[SRS: Constancias de Plática para Público en General](../srs-constancias-platicas.md)**: Especificación formal, tokens criptográficos AES-256-GCM, homologación de componentes y arquitectura del módulo de constancias para asistentes comunitarios.
