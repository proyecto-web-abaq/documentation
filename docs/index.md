## Tecnologías Principales

El sistema se basa en una arquitectura desacoplada y orientada a la seguridad:

=== "Frontend (Cliente)"
    * **Angular 19** con Standalone Components e inyección de dependencias `inject()`.
    * **Arquitectura Reactiva**: Flujos de datos con RxJS (`Observable`, `BehaviorSubject`).
    * **Diseño Responsivo**: Sistema visual institucional en SCSS con soporte para móviles, tablets y desktop.
    * **Rutas y Seguridad**: `AuthGuard`, `PublicGuard` y `OnboardingGuard` con control por `accountStatus`.

=== "Backend (API REST)"
    * **Node.js (LTS v20+)** con framework Express.
    * **Control de Acceso Estricto**: Middleware `requireActiveAccount` (`403 Forbidden` a cuentas `pending`/`rejected`).
    * **Seguridad de Sesión**: Cifrado con tokens JWT y hashes de contraseñas con bcrypt.
    * **Generación Criptográfica de Constancias**: Firma HMAC-SHA256 para verificación de certificados públicos.

=== "Base de Datos & Almacenamiento"
    * **MongoDB Atlas (Cloud)** con Mongoose ODM.
    * **Identificadores Obligatorios**: Folio institucional inmutable (`SS-YYMMDD-HEX` / `VG-YYMMDD-HEX`) obligatorio para el 100% de los registros.
    * **Almacenamiento Desacoplado**: Enlaces en la nube (Cloud URLs) para INE, CV y comprobantes sin saturación de almacenamiento local.

=== "Seguridad, DevOps & Documentación"
    * **Cloudflare Proxy & WAF**: Mitigación de ataques DDoS, Rate Limiting y anti-bots con Cloudflare Turnstile.
    * **Infraestructura Cloud**: Arquitecturas evaluadas para Microsoft Azure bajo grant institucional.
    * **CI/CD**: Pipelines de validación continua con GitHub Actions.
    * **Documentación Técnica**: Generador de sitios Zensical (Material for MkDocs) con motor Python y compilación instantánea.
